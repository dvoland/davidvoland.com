Student Events & Follow-Ups

QuickMark: Teacher Tracker

Keep track of the little things before they become big things.

QuickMark is a lightweight teacher utility for quickly recording student events and remembering what needs to happen next. It sits alongside your school’s existing systems. It is not a gradebook, attendance system, or student information system.

Coming Soon

Log it in seconds

Select a student, tap an event, and you’re done. Track positive moments like great sportsmanship or helping a classmate, as well as everyday concerns like tardies, phone use, or uniform issues. Create your own event types to fit your classroom.

Notice the pattern

Every student has a running history. Sort and filter by event counts, event type, follow-up status, and time period so you can answer questions like, “Who has had uniform issues this week?”

Don’t forget the follow-up

Create simple rules that turn repeated events into TO-DOs. If three phone incidents mean it’s time for a parent contact, QuickMark can add that follow-up so you don’t have to remember it yourself.

Organize students by class, import rosters from CSV or Excel, add notes when extra context matters, and optionally add student photos. Previous class history stays available without carrying old counts into a fresh start.
